# F5：FREE 用了掌面接触；L4 可观测性实测

**日期：** 2026-09-23
**性质：** 两项检查。`check_l4_observability.py`、`out/l4_observability.json`。只读，未修改任何文件。

---

## 一、FREE 的 MPC 用不用掌面接触？——**用**

`contact/allegro_collision_detection.py::detect_once` 的过滤条件只有一条：

```python
if (geom1_name in self.param_.object_names_):
    ...
elif (geom2_name in self.param_.object_names_):
```

**只要接触涉及物体就纳入，不区分掌面还是指尖。** 所以 FREE 的 MPC 模型包含掌面接触，
它知道物体被掌面托着。这与 agent 实测的接触分布一致（cube：palm 1185 次 vs fingertip 121 次）。

**含义：** "FREE 靠手指做到"的真实含义是**执行靠手指，建模什么都不缺**。
重力主要由掌面承担，手指只负责转动。任务比"纯指尖悬空把玩"容易得多。

## 二、L4（模型无关版）：合法动作能让触觉观测变化多少？

不假设任何离散"接触模式"（F3 已显示 FREE 里它不自然存在），只测可直接观测的量：
四指尖法向载荷、全接触载荷、以及各动作相对基准动作的变化。

**样本：** cube / mug / stick 的 nominal，共 12 个恢复状态，每状态 8 个合法扰动动作（±0.02 rad）。

### 结果

| 观察 | 数值 |
| --- | --- |
| **指尖读数恒为零、且任何动作都不改变它的状态** | **8 / 12（67%）** |
| 这些状态下掌面承载 | 2–4 个接触，全接触载荷中位 **0.97 N** |
| 其余 4 个状态的指尖载荷 | 1.02 / 2.27 / 2.38 / 3.99 N |
| 这些状态里动作能改变读数的幅度 | 0.048 – 0.270 N |
| Spearman(触觉变化, 任务推进) | −0.52 / −0.57 / −0.71 / −0.60 |

### 结论（两条，一条强一条弱）

**强：大多数状态下，指尖触觉通道读到的正好是零，而载荷在掌面上。**
12 个状态里 8 个如此，且**任何合法动作都无法让指尖读出东西**——不是"信号弱"，是"完全零"。

**弱（且必须标注混淆）：** 在有信号的 4 个状态里，触觉变化与任务推进呈负相关。但
**这个相关系数被扰动幅度混淆**——扰动越大，既越可能改变触觉、也越可能损害任务推进。
每个状态只有 8 个样本，**不足以支撑"探索与利用相冲突"这个结论**。不得这样写。

### 适用范围（硬限制）

- 这是 **on-palm 重定向**场景：物体起始就搁在掌面上。**不能推广到悬空在手内把玩。**
- 只在 nominal 的 3 个物体、12 个状态上；pilot，不得升格为结论。
- 指尖载荷由 `fingertip0..3` 四个 geom 的接触力求和得到。

### 一处必须记录的工具错误

第一版脚本用 `other.startswith("ftp_")` 识别指尖，但手部 geom 实际叫
`fingertip0..3`（`ftp_0..3` 是 **site** 不是 geom）。修正前所有状态都报"指尖载荷为零"，
看起来像一个漂亮结论，实际是过滤器写错。**已修正后重跑，上表是修正后的数字。**
