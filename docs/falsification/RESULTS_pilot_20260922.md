# 证伪 pilot 结果与口径统一（2026-09-22）

**性质：** pilot。只有 cube nominal 前 8–10 帧。**不足以支撑任何 L1–L4 的结论。**
**本文件目的：** 把并行 agent 产出的多个脚本、多套口径收敛成一套，并区分「已确认」「待复核」「已排除」。

---

## 0. 先说一个必须解决的问题：现在有四套口径

并行产出了四个脚本，各自用的残差/归一化定义不同，直接导致结论互相矛盾：

| 脚本 | 残差定义 | 归一化分母 |
| --- | --- | --- |
| `check_core_relation.py` | $\|A_hx+J_h\delta q\|$ | 无（绝对量） |
| `check_discrimination.py` | 同上 | $\|J_h\delta q\|$（接触点运动尺度） |
| `check_single_step.py` | 同上 | $\|x_{\text{obs}}\|$（**危险**） |
| `check_row_structure.py` | 分三种行结构 | 无（绝对量） |

**冲突本身就是产出。** 同一个 step 6，在第二套口径下是 1e8，在第三套口径下炸到 1e9，在绝对量下只有 1e-4。四套并存比没有更糟：任何一方都能挑一套支持自己的结论。

**结论：所有指标必须走同一个 metrics 模块，一个量只有一个定义。** 在统一之前，任何 L1–L4 数字都不该写进报告。

## 1. 已确认（我独立复现，四次运行一致）

### 1.1 控制区间尺度上，一阶线性化不可用

在真值接触集上，用**正确的三行黏着判据**（接触系 $n,t_1,t_2$）计算接触点相对速度违反量：

| step | n 真值接触 | $\|\delta q_{\text{hand}}\|$ | stick3 违反量 |
| ---: | ---: | ---: | ---: |
| 0 | 2 | 0.207 | 0.0232 |
| 1 | 3 | 0.156 | 0.0077 |
| 2 | 2 | 0.153 | 0.0060 |
| 3 | 4 | 0.184 | 0.0120 |
| 4 | 3 | 0.239 | 0.0191 |
| 5 | 8 | 0.208 | 0.0089 |
| 6 | 5 | 0.095 | 0.0001 |
| 7 | 5 | 0.090 | 0.0000 |

接触点的自身运动尺度（$\|J\delta q\|$）在 step 3 约 0.011。**违反量与信号同量级。**

对象侧预测同样失效：adequacy $\|x_{\text{pred}}-x_{\text{obs}}\|/\|x_{\text{obs}}\|$ 在**满秩帧**上仍是 1.00–2.42，即"预测物体运动"不比"预测物体不动"更好。

**含义（这是设计层的硬约束，不是调参问题）：**
> 在 0.1 s / 约 0.2 rad 的动作尺度上，$\delta q$ 不能用来预测物体位移。
> L1–L4 **必须**在单一物理步、或已有的 $\pm0.002/0.004$ rad ε-探针分支上做。

这与预期一致：0.1 s 内接触点本来就会滚动/切换，"黏着"作为整段约束本来就不成立。**不是模型写错了，是尺度选错了。**

### 1.2 行结构不是主因（新增检查，排除了一个替代解释）

我加了 `check_row_structure.py`，比较三种行结构：三行黏着、仅法向、FREE 的摩擦锥行 $n+\mu t$。

同一批帧上，**三者量级接近**（step 3：0.0120 / 0.0066 / 0.0141）。

所以 1.1 的结论**不是**"因为用了错的摩擦锥行才失效"——改用正确的黏着行，违反量照旧。这一条替代解释被排除。

### 1.3 近静态帧的相对量是纯数值伪影

step 6/7 的绝对违反量只有 $10^{-4}$–$10^{-5}$，但物体位移 $x_{\text{obs}}$ 也接近零（$10^{-3}$–$10^{-6}$），于是除以它的相对量炸到 $10^7$–$10^9$。

**这不是"世界的性质"，是我们自己的实现陷阱** —— 正是"第三种证伪"（自己的实现没检测出来）的活体样本。

**规则：** 禁止在任何判据里除以 $\|x_{\text{obs}}\|$；近静态帧必须按绝对量剔除；剔除判据用「物体位移绝对值 $<\epsilon_x$」，不用相对量。

### 1.4 真值接触集常常不满秩

cube nominal 前 8 帧的真值接触集秩为 **3, 6, 5, 6, 6, 6, 6, 6**。有 2/8 帧不满秩，最小到 3。

**含义：** 原规范里"要求 $\operatorname{rank}(A_h)=6$ 否则丢弃"会把**真值假设本身丢掉**。必须改为：允许 rank < 6，显式记录 $\text{null\_dim}=6-\operatorname{rank}$，并把所有涉及 $T_h$ 的量写成条件性结论（"在约束能确定的子空间上……"）。

## 2. 待复核：agent 报告过、但我认为证据不足的一条

agent 报告："把真值接触集去掉任一个接触，rank 仍是 6，consistency 几乎不变（step 3：0.144 → 0.065–0.144；step 5：0.491 → 0.424–0.491）"，并据此认为这是"多个假设与观测相容"的直接证据。

**我认为这条现在不能用，理由是它被 1.1 污染了。**

当模型在该尺度上根本不成立时（违反量与信号同量级），**删掉约束必然改善拟合**——这是模型失效的退化后果，不是"真歧义"的证据。在模型不成立的地方，"所有假设都相容"是平凡结论。

所以：
- 这条**不能**作为 L1 的证据；
- 它必须等 L1 搬到单步 / ε-探针尺度之后重做；
- 届时的判据必须是**两侧的**（consistency 与 adequacy 同时看），只看残差会系统性偏向"删接触"的假设。

## 4. 由 pilot 直接推出的设计修正

这些不是建议，是**已经在数据上被证伪的东西**，必须改：

1. **时间尺度。** 运动学关系只能在单物理步或 ε-探针（0.002 rad）尺度上用。设计文档里"滚动流形上推进目标姿态"的整段动作，不能用这个关系直接预测；要么退化到逐步、要么另建尺度桥接（例如用实际 $\delta q$ 而非 $u$ 的在线响应）。
2. **禁止相对量分母。** 任何除以 $\|x_{\text{obs}}\|$ 的判据作废。
3. **近静态帧剔除。** 判据用绝对量。
4. **rank 条件放宽。** 记录 null_dim，做条件性陈述，不丢帧。
5. **单一口径。** 所有指标走一个 metrics 模块。
6. **两侧判据。** 只看残差会偏向"删接触"的假设，必须同时看 adequacy。

---

## 5. 这次 pilot 真正的价值

它没有回答"歧义是否存在"，但它回答了三个**更前置**的问题：

1. 运动学关系在什么尺度上成立 → 不成立的地方在哪，明确了。
2. 我们的测量口径有几种互相矛盾的写法 → 收敛成一套。
3. "多个假设都相容"这个现象要小心解释 → 可能是真歧义，也可能只是模型失效的退化后果。

**第 3 条是最重要的。** 如果我们不做这个区分，就会拿着一堆"所有假设都相容"的结果去宣布发现了歧义，而那其实只是模型在该尺度上不可用。
