## 2. 为什么这个"通过"不是好消息的全部：两个问题被混淆了

**问题 A（触觉传感覆盖）：** 四指尖触觉能否看到全部承载接触？
→ **不能。161/167 = 96.41%** 的基准帧含四指尖**看不见**的有载荷接触。
（本 agent 独立复现，与 `observation_sufficiency_20260922.md` 第 36 行逐位一致；阈值 0.01 N → 161 帧、0.1 N → 130 帧也逐位一致。分母 **167 = `probe_sign == 0` 的基准帧数**，不是 183；全 183 行口径下是 177/183 = 96.7%。）

**问题 B（几何候选覆盖）：** 用已知 CAD + 关节角 + 物体位姿做几何邻近，能否覆盖全部承载接触？
→ **能。167/167 = 100%，漏检 0。**

**这是两个不同的问题，答案相反。** 96.4% 这个数字说的是 A，而闸门问的是 B。把它当成 B 的证据，就得出"闸门不过"的错误预判。

787 条未覆盖接触分布在 **13 个手部 geom** 上：`palm` 519、`th_base` 56、`th_distal` 50、`rf_proximal` 41、`mf_base` 27、`ff_distal` 25、`th_medial` 20、`rf_medial` 19、`rf_distal` 13、`rf_base` 11、`mf_proximal` 5、`ff_medial` 1。
**几何邻近把它们全部找回来了**——接触必然伴随邻近，这是构造性的。

## 3. 必须与这个 `pass` 同时陈述的两条 caveat（否则结论被高估）

**3.1 候选生成用了真值物体位姿（PRIVILEGED）。**
`check_coverage.py` 在记录的真值 `state` 上跑 `mj_forward + mj_collision`。部署时物体位姿来自**视觉估计**，有误差。**位姿误差如何影响覆盖率，本闸门完全没测。** 一个 1 mm 的位姿误差足以在窄带边缘翻转候选的存在性。

**3.2 候选与真值同源 → 本闸门在此仪表下近乎同义反复。**
候选来自 MuJoCo 碰撞检测，真值也来自 MuJoCo 碰撞检测（同一状态）。**100% 覆盖是这个同源性的产物，不是关于世界的发现。** 唯一非平凡的内容是 §1 的两项：**候选集大小**与**误报率**。

要把这道闸门变成真正的检验，必须用**与被测仿真器不同源**的几何模型重做（例如从 CAD mesh 解析计算距离），或换成真实传感数据。本阶段未做。

## 4. 这个结果排除了多少搜索空间

**排除了一整类设计上的悲观假设**，而且它是可证伪的、非平凡的：

1. **排除了"隐藏支撑占主导、信念长期不收敛、$\rho_t$ 必须一直很小、任务几乎不走"这个预言**
   （`algorithm_design_blind_tactile_play.md` §334 列为头号风险）。**给定物体位姿，隐藏支撑在几何上是可枚举的**，数量还很少（每帧 1–6 个候选对）。
2. **排除了"接触集合本身是歧义的主要来源"这个定位。** 几何几乎唯一确定接触集合（误报率 1.56%）。

**由此得到的正面结论（本次最重要的产出）：**

> **瓶颈不在"哪些接触存在"，而在"这些接触处于什么模式、承载多少"。**
> 前者几何几乎给定；后者**几何完全给不了**，只能靠触觉/力/运动响应。

这直接改写 L1 的提法：L1 不该问"接触存在性上是否存在歧义"（答案近乎唯一），而该问"**接触模式/载荷上是否存在会改变动作选择的歧义**"。这也和 `RESULTS_L1_probe.md` §4 的结果吻合——真值接触里同时存在明显滑动与明显黏着（STICK 比例三档下 4.3%–43%），**模式变量非平凡，存在性变量近乎平凡**。
