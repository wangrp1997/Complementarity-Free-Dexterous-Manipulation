# 证伪协议：任务相关触觉消歧在手内重定向中是否成立

**日期：** 2026-09-22
**性质：** 预注册协议。判据在跑之前写死，避免事后解释。
**适用：** FREE / Allegro 现有设定，动作接口 $u_t\in\mathbb R^{16}$，不涉及欠驱动手。
**配套：** 几何可行性见 [geometry_feasibility.md](geometry_feasibility.md)，文献核查见 [task_relevant_info_lit.md](task_relevant_info_lit.md)，数据与 L1 规范见 [l1_spec_and_data_audit.md](l1_spec_and_data_audit.md)。

---

## 0. 这份文档要解决的一个误解

证伪不能脱离设计。你只能证伪一个**具体到能做出预测的主张**。所以本文档不是"先证伪、再设计"，而是**先把设计里承载主张的那一小块切出来，单独验它**。

因此下面的阶梯验的是**主张**，不是**实现**：

- **主张**（决定方法能不能成立）：接触假设表示、$A_mx=J_m\delta q$、任务相关投影 $\Pi$、一步 argmin。$\to$ 就是 L1–L5 验的东西。
- **实现**（只决定做得多好）：优化器怎么写、阈值取多少、换指策略怎么触发。$\to$ 不在证伪范围内，失败也不算主张塌了。

一句话：**证伪的对象是命题，不是代码。**

---

## 1. 待验主张的精确形式

> **H（任务相关触觉消歧）**
> 在 FREE / Allegro 设定下，存在一类接触歧义，使得：
> (a) 与允许观测相容的多个接触假设，给出的**任务相关**预测不同；
> (b) 这些假设会导出**不同的最优动作**；
> (c) 存在同时满足关节限位、幅度约束与包络约束的**合法动作**能区分它们；
> (d) 执行该动作消歧后，在**等预算**下任务成功率或效率有可重复改善。

H 是合取命题。**任何一条不成立，H 就不成立**——但"不成立"是诊断信息，不是项目终点（见 §7）。

(a)(b)(c) 全部可以离线判定，(d) 需要闭环。所以阶梯前四级不写控制器就能跑，这正是不先建控制器的理由。

## 2. 阶梯 L1–L5

每一级都必须报告**全部结果**，包括没有分岔的快照。只报成功的样本等于没做。

### L1 — 歧义存在吗

**判定量。** 只用允许观测构造假设集 $M_{\text{obs}}$（指尖取 `STICK/SLIDE_N/FREE`，掌面指节按 CAD 窄带生成候选取同三种模式）。用**实际**关节变化 $\delta q=q_{t+1}-q_t$ 计算残差
$$r_m=A_mx_{\text{obs}}-J_m\delta q .$$
保留 $R(m)\le\tau$ 的相容假设集合 $M^\*$。

**通过：** $|M^\*|>1$，即至少两个假设都与观测相容。
**不通过的含义：** 允许观测在当前状态下已经唯一确定接触模式。**"用触觉消歧"这个前提在这些状态上不存在。** 这是穷尽性结论，不是"我没做出来"。
**修法：** 检查假设集是否建得太窄（漏了候选接触）；或换到掌面参与更多的状态；或承认该状态无需消歧。

### L2 — 歧义影响任务吗

**判定量。** 跨相容假设的**任务代价离散度**
$$W=\max_{m\in M^\*} g^\top x_m^\*-\min_{m\in M^\*} g^\top x_m^\*,$$
以及每个假设的零空间半宽 $r\|P_{\ker A_m}g\|$。

**通过：** $W>0$ 且超过由 §5 声明的阈值。
**不通过的含义：** 歧义真实存在，但对"转到目标姿态"**无所谓**。加多少触觉都没用，因为任务不关心。
**修法：** 换任务方向（比如加入平移分量、换成需要接触力的任务）；或接受该歧义无需消解。

### L3 — 歧义会改变动作吗（命门）

**判定量。** 对每个相容假设各求最优动作 $u^\*_m=\arg\min_u J_{\text{task}}(u;m)$，看
$$\Delta_u=\max_{m,m'\in M^\*}\big\|\Pi(u^\*_m-u^\*_{m'})\big\| .$$

**通过：** $\Delta_u>\delta_u$。
**不通过的含义：** **歧义真实、对任务有影响，但所有假设都指向同一个动作。** 那就没有探索的必要——直接做那个动作就行。这是"歧义存在 ≠ 探索有用"的分界线，也是整套设计的命门。
**修法：** 若长期不通过，说明任务相关过滤把所有歧义都滤掉了，机制在此任务上无立足点。这是**必须如实报告的负结果**。

### L4 — 存在合法分离动作吗

**判定量。** 在可行集
$$\mathcal U=\{u:\ q_{\min}\le q+u\le q_{\max},\ \|u\|_\infty\le\rho,\ \text{enclosure}(u)\ge\text{thr}\}$$
中，检查是否存在 $u$ 使
$$D(u)=\sum_{m}w_m\big\|\Pi(K_m-\bar K)u\big\|^2_{\Sigma^{-1}}>\tau_D .$$

因为 $D$ 是二次型、$\mathcal U$ 近似凸，这是小规模可行性问题，**可以穷尽回答**。

**通过：** 存在分离动作。
**不通过的含义：** **单步内不存在能区分它们的合法动作。** 这是**条件性**的强负面结果：只在「同一表示、同一动作接口、单步」下成立，别人换表示或换接口就是另一套理论，那个界不适用（这一点必须写进结论）。
**修法：** 明确指向下一问——两步行不行？连续三步？换指（松—挪—接）行不行？**是推进，不是终点。**

### L5 — 消歧带来任务收益吗

**判定量。** 闭环等预算对照，四组：

| 组 | 说明 |
| --- | --- |
| FREE（原样） | 主基线。它**不用触觉**，信息预算更少，比较是公平的。 |
| ours − probe | 同样状态与优化，关掉 $D(u)$。检验"主动"的净贡献。 |
| ours + 通用信息 | 通用信息量替代任务相关项。检验"任务相关"是否必要。 |
| ours + 任务相关 probe | 本文方法。 |

固定：完整初始仿真状态、成功率判据、动作预算、时间预算、计算预算。

**指标：** 目标姿态成功率、姿态误差、掉落率、失接触次数、峰值载荷、到达时间、**交互步数**、信念熵轨迹、P0 探索预算消耗。

**通过：** 任务相关 probe 在等预算下重复优于另外三组。
**不通过的含义：** 信息有收益但代价更高，或收益来自多试探而非任务相关性。属于诚实负结果。

## 3. 两个辅助检查（不需要新表示）

### A. 失败归因

已知 stick 在失配下从 13/20 掉到 2/20。取这些失败 trial，检查失败前后若干帧是否出现**触觉上可观测的签名**：接触脱离、法向载荷骤降、切向相对位移超阈、接触点关联失败。

**判读：** 若失败时刻**没有任何可观测签名**，这类失败不是接触信息问题，触觉探索救不了。这会把机制从相关失败模式里直接排除——省掉整条弯路。
**前置：** 需要确认现有记录是否保存了足够的逐步状态（见 l1_spec_and_data_audit.md）。这项检查可能因为数据不足而无法做，那就如实报告"无法归因"。

### B. Oracle 上界（最能防自欺）

**目的：** 回答"如果接触信息全知道，能提升多少"。

**做法：** 构造 oracle 观测 = 允许观测 + labels 里的**真实接触集合**（含掌面/指节），喂给**同一个**优化器，同初态、同预算跑。

**判读（三条，都很重要）：**

| 观察 | 结论 |
| --- | --- |
| oracle ≈ FREE | 失败**不是**接触知识问题。整个触觉故事跑偏，该去查动作空间、规划或控制。 |
| oracle ≫ FREE | 接触知识确实是瓶颈，机制有空间，值得继续。 |
| oracle ≫ ours（ours 能跑之后） | 我们没把可用信息用够，问题是估计而非感知。 |

**边界声明：** oracle 只是**上界诊断**，不能作为方法发布；它仍是"在这个控制器家族内"的上界，不是绝对上界。labels 只能进 oracle 和审计，**永远不能进控制器**。

## 4. 预注册判据表

跑之前定死，跑之后不改。任何修改都要新开一版并说明原因。

| 级别 | 通过条件 | 不通过时的新 claim（fallback） |
| --- | --- | --- |
| L1 | $\|M^\*\|>1$ 的快照占比 $\ge p_1$ | "在多数操作状态下，允许观测已唯一确定接触模式" —— 感知接口的边界结果 |
| L2 | $W>\tau_W$ 的快照占比 $\ge p_2$ | "在手重定向中的接触歧义大多与任务方向正交" —— 任务设计的边界结果 |
| L3 | $\Delta_u>\delta_u$ 的快照占比 $\ge p_3$ | "存在任务相关歧义但不改变动作" —— 否定主动探索的必要性，直接做贪心 |
| L4 | 存在分离动作的快照占比 $\ge p_4$ | "单步内不可分" —— 条件性不可能结果，指向多步/换指 |
| L5 | 等预算下任务相关 probe 重复占优 | "有信息收益但代价更高" —— 诚实负结果 |

**$p_1..p_4$ 的具体取值必须在开跑前由样本量决定并写入本表，不能事后调。** 现有数据只有 167 帧、4 个合格配对快照，因此这些比例的置信区间会很宽——这本身就是需要提前承认的限制（见 §6）。

## 5. 阈值从哪来（不能拍脑袋）

这是最容易自欺的一环：**仿真无噪声**，很容易把阈值定得极小，于是"发现"一大堆实际上不可分的歧义。

阈值只能来自以下三个可辩护来源之一，且必须显式声明用了哪一个：

1. **数值精度**（浮点、求解器容差）——只能用于排除纯数值伪影。
2. **模型误差**——已有实测：指令与实际关节变化的相对差 **34.7%–51.4%**。用于残差的阈值必须至少反映这个量级，否则会把伺服误差当成模式差异。
3. **离散化**——MuJoCo 的接触点离散化（实测多点记录点集直径中位数约 0.047 mm）。用于接触点关联的阈值必须反映它。

**强制敏感性分析：** 每个阈值在 $\times 0.1$、$\times 1$、$\times 10$ 三档重跑，报告结论是否翻转。**结论对阈值敏感 = 结论不成立**，必须如实写出来。

## 6. 样本量与统计（提前承认的限制）

- 现有 167 个基准时刻，其中**只有 4 个合格配对快照**，每个只探测一个关节方向。
- 因此 L1–L3 可以在 167 帧上做描述性统计，但**不能**用"3 帧通过"宣布机制成立。
- 最低要求：报告**全部**快照的通过/不通过、通过比例及其置信区间、以及没有分岔的那些样本的特征（它们为什么没有）。
- L4 的"不存在分离动作"要对**所有**检验过的假设对成立才叫强负面；只要有一个反例，它就是弱负面。

---

## 7. 失败时的处理原则

**证伪的是主张，不是项目。** 每一级挂掉都换成一个新 claim，而不是终止。四个 fallback 已写在 §4，且都要求同样具体、同样可证伪。

同时守住两条纪律：

1. **不许悄悄挪球门。** 拿到 null 就改假设集/改阈值/改任务方向，等于什么都没验。要改就显式新开一版协议。
2. **不许把弱负面当结论。** 判断标准只有一句：**这个负面排除了多少搜索空间？** 只排除"我这次的实现"——那是日志，不是结论。

## 8. 本协议不做的事

- 不在这个阶段建控制器、不训练、不做 RL 对照（RL 对照属于后续 Isaac Lab 侧）。
- 不声称解决 POISE / WM-Craftnet / Tacmap 的任何 gap。
- 不声称未知动力学下的安全、状态充分性、Markov 性、跨手型泛化。
- 不涉及欠驱动手；那需要另建模型，属于后续章节。
- 不修改 FREE 任何文件。ours 只新增。改完前后做 SHA-256 比对 + 重跑 17 物体基准确认基线未变。
