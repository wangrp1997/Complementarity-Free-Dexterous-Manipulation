## 1. 本文件解决的三个问题

1. `falsification_spec.md` 给出了判据形式，但多个阈值（$d_{\max}$、$\kappa$、$\tau_u$ 等）**只写了"现场标定"或给了单一默认值**，没有规定**换档后结论需不需要一致**。没有这条纪律，"现场标定"就等于"事后调参"。
2. 现有判据是二值的（通过 / 失败），但至少有一种情形**两个都不是**（见 §4）。
3. 本文件落盘后需要**指纹**，供后续比对是否被静默修改。

## 2. 阈值登记表

右列"稳健性档位"是本文件新增的强制要求：**同一阈值必须至少在 3 档上各跑一次，三档全报**。

| 阈值 | `falsification_spec.md` 的口径 | 稳健性档位（新增） | 依据 |
| --- | --- | --- | --- |
| 候选距离带 $d_{\max}$ | 取与物体表面距离小于 $d_{\max}$ 的几何为候选 | 0.5 / 1.0 / 2.0 mm | 需与 CAD 网格精度、接触点离散尺度（点集直径中位数约 0.047 mm）相容 |
| 候选数上限 $K_{\max}$ | 默认 6 | 4 / 6 / 8 | 枚举预算 |
| 相容集系数 $\kappa$ | 默认 3，$r_h\le\max(\tau_{\mathrm{abs}},\kappa r_{\min})$ | 2 / 3 / 5 | 残差谱 |
| 绝对残差 $\tau_{\mathrm{abs}}$ | **现场标定** | 必须与 $\kappa$ 联合给两档 | 不得凭空设定；必须报取值与依据 |
| 任务分歧 $\tau_{\mathrm{task}}$ | 以当前任务代价尺度归一化 | 两档相对量 | 不得写成绝对数值 |
| 动作分歧 $\tau_u$ | 默认 0.10 | 0.05 / 0.10 / 0.20 | 指令范数归一 |
| 探测幅度 $\varepsilon_{\mathrm{probe}}$ | $\{0.002, 0.004\}$ rad | **两档必须同号** | 与已采集探针一致，便于用实测分支验证 |
| 秩要求 | $\operatorname{rank}(A_h)=6$ | 另报最小奇异值 | 见 §4 第 2 条的"未判定" |
| 岭正则 $\lambda$ | 取 FREE 控制代价同量级，并报 $\lambda=0$ 对照 | 两档 | 防止结论依赖正则项 |
| 零空间球半径 $r$ | **不适用** | — | spec 用动作盒 $D$ 求 $\max_{u\in D}g^\top T_hu$，等价于把 $r$ 换成由关节限位与动作盒导出的量。**这是正确做法**，登记为强制；禁止再出现任意赋值的 $r$ |

**结论稳健性规则（强制）：**

- 三档中 **≥2 档**给出同一判定 → 记为**稳健**，可作为主结论；
- 只有 **1 档**成立 → 必须标注为**阈值依赖**，只进附录或作为后续工作动机，**不得**作为主结论；
- 三档给出三种不同判定 → 视为**未判定**，需先查标定方法再重跑。

## 3. 报告强制字段（每级都要有）

1. 通过 / 失败判定；
2. 具体数字（$\|H_c\|$ 分布、覆盖率、$\tau_{\mathrm{task}}$、分岔比例、$\|u^*_{h_1}-u^*_{h_2}\|$ 等）；
3. **阈值如何标定**，以及三档敏感性是否翻转；
4. 用了哪些**白名单**字段；
5. 哪些地方用了 `PRIVILEGED` 字段（labels 仅用于覆盖率审计与 Oracle 上界）；
6. **结论的有效范围**（表示、动作接口、观测预算三要素）；
7. 本次**没能确认**的部分。

第 6 项缺失即视为"把 (b) 写成 (a)"，退回重写。

## 4. 第三类判定：未判定

现有判据是二值的，但至少两种情形两边都不属于，必须单列，**不得**被归入"失败"来制造负面结论：

**第 1 类：残差谱无明显间隙。** 若 $r_h$ 的分布没有清晰的双峰或间隙，$\kappa$ 就决定了 $|H_c|$，此时 L1 的"存在/不存在歧义"是阈值的人为产物。判为**未判定**，需改用有依据的噪声模型（例如由实测探针响应尺度标定）再判。

**第 2 类：半宽为零但秩可疑。** L2 用 $r\|P_{\ker A_h}g\|$（或等价形式）判任务相关性时，若半宽为零**而** $A_h$ 的最小奇异值低于声明下限，则"零空间项为零"是数值满秩的几何巧合，**不等于**认知完整（`method_routes/review.md` 第 3 节已明确警告）。判为**未判定**，不计入通过也不计入失败。

**第 2 类的判别：**

- 半宽为零 **且** 最小奇异值高于下限 → 判为"**与任务正交**"，是真结论（歧义无害）；
- 半宽为零 **但** 最小奇异值低于下限 → 判为**未判定**。

已知双指快照的全点矩阵最小奇异值仅 **0.00064–0.00102**（长度尺度 0.05 m），三指快照约 **0.617**，因此这一条不是空想的边界情形。

## 5. 反自欺条款

与 [README §5](README.md) 一致。本文件只补充与阈值直接相关的一条：

> **不允许在同一个数据上先看结果再改阈值。** 阈值只能来自本文件 §2 的档位、实测探针的响应尺度，或明确声明来源的噪声模型。任何放宽必须在报告中以 `RELAXED: <what>` 标记并说明理由，且放宽后的结论自动降级为**未判定**。
