# F7：换到 fingertips in-air（三点悬空指握）后的三项复查

**日期：** 2026-09-23
**产物：** `check_fingertips_air.py`、`out/fingertips_air_probe.json`。只读，未改 FREE。
**前提：** `ours/tactile_observation.py` 已参数化（提交 `41f4abc`），`metrics.score` 已泛化到任意手部自由度。

---

## 0. 先确认工具可信

打桩运行与干净运行**逐位一致**：`SUCCESS steps=183 quat_err=0.0003 z=0.099`。
反事实在**独立克隆环境**上执行，主轨迹不受影响。

## 1. 结果

| 指标 | 值 |
| --- | --- |
| 控制步数 | 183 |
| 悬空步数（桌面载荷 = 0） | **72（39.3%）** |
| 悬空段指尖载荷 | 0 – **1.06 N** |
| 悬空段指尖接触数 | **0, 1, 2, 3**（含完全无接触的自由飞行） |
| **悬空段 consistency 中位** | **0.457**（min 0.066，max 1.519，n=70） |
| 悬空段秩 | 0, 3, 6 |
| 反事实探测（10 次） | Δ指尖载荷 中位 **0.011 N**，max 0.066 N |
| 零响应探测 | **4 / 10** |

## 2. 三条读法

**一、刚性关系明显变好，但仍不成立。**
Allegro on-palm 上 consistency 中位是 1.2–2.4；这里降到 **0.457**，最小值 0.066——**有些状态几乎成立**。
但中位仍在 0.46，最大值 1.52，**整体仍不能当硬约束用**。这是"变好"，不是"可用"。

**二、触觉通道活了。**
指尖载荷到 1.06 N，不再是 Allegro 那种整段读到零。这是换设定最直接的收益。

**三、但动作对触觉的影响很弱。**
指令扰动 10% 只让指尖载荷变化中位 **0.011 N**（约基线的 1–2%），而且 **4/10 次探测完全没有响应**。
那 4 次大概率落在非悬空步（物体还在桌上、指尖载荷为零），但无论如何：**在小扰动下，触觉对动作不敏感。**
这与"载荷主要由控制器内力和阻抗维持、不由位置指令决定"一致。

## 3. 必须一起说的限定

- **单物体（cube）、单 seed、单次运行**。pilot，不得升格为结论。
- 反事实扰动幅度是"典型指令幅值的 10%"，来源是启发式，未做敏感性扫描。
- 零响应那 4 次**未逐条核实**是否都落在非悬空步——这是本报告的一个未完成项。
- 悬空段里 `n_ft = 0` 的步数存在，说明"桌面载荷为零"不等于"被指尖握着"，两者要分开统计。

## 4. 对下一步的含义

**通道对了、关系变好但没成立，而动作→触觉的灵敏度很低。**
这三点合起来意味着：靠"改一个动作看触觉怎么变"来做决策，在这个设定下信号很弱。
真正还值得测的是**大幅度动作**（而不是 10% 小扰动）下的响应，以及**接触数变化**（0→1→3）这个更离散、更可能可观测的事件。
