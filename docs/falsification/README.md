# 证伪阶梯 L1–L4：总纲、决策树与预先承诺

**日期：** 2026-09-22
**状态：** 规范草案。不含实现，不含实验结果。
**上游文档：** [../algorithm_design_blind_tactile_play.md](../algorithm_design_blind_tactile_play.md)、[../research_decision_20260922.md](../research_decision_20260922.md)、[../tactile_state_spec.md](../tactile_state_spec.md)

本文只回答一个问题：**在投入控制器之前，按什么顺序、用什么判据，判断这套机制的主张是否成立；每一级挂掉之后走哪条路。**

---

## 0. 先厘清一件容易混淆的事：证伪不可能不设计

要证伪一个理论，这个理论必须具体到能做出预测。模糊的研究问题做不出预测，因此也无法被证伪。所以「先证伪、再设计」这个顺序本身是错的；真实顺序永远是：**先设计一个最小但足够具体的主张，再去证伪它**。

本阶梯里出现的接触假设表示、残差式、任务相关投影、一步 argmin，**都是主张**——它们决定这套方法能不能成立。优化器怎么写、阈值取多少、换指什么时候触发、用什么求解器，**都是实现**——它们只影响做得多好，不影响主张的真假。

所以本阶梯不是「流程说明」，而是**把设计里承载主张的那一小块切出来，先验它**。

买到的不是省掉设计，是**便宜的放弃**：几天收场，而不是搭完优化器、安全层、换指之后几个月才发现内核不通。后者最危险的地方不是浪费，是到那时你已经很难承认它不通。

## 1. 两类负面结论，只有一类值得写进论文

这是整套方法论里最需要纪律的一条。

| 类型 | 长什么样 | 会被更强的算法推翻吗 | 能写进论文吗 |
| --- | --- | --- | --- |
| **关于世界的负面** | 在给定动作接口、关节限位、包络约束下，可行集里不存在能区分这两个假设的方向 | **不会。** 可行集是问题本身的性质，不是求解器的能力 | 能。而且是持久的一类贡献 |
| **关于我的方法的负面** | 触觉主动探索对在手操作没用 / 我这次没做出来 | **会。** 只要有人做出更好的策略就推翻 | 不能。「我这次没成」是日志，不是结论 |

**唯一的判别标准：这个负面结果排除了多少搜索空间？**

- 只排除「我这次的实现」→ 日志。
- 排除一个有定义、非平凡的子空间 → 金子。

因此本阶梯的每一级都必须尽量设计成**对可行集的穷尽检查**，而不是「跑一下看看行不行」。后者只能产出弱负面，弱负面不能用来关闭任何方向。

---

## 2. 阶梯全貌

链条：**歧义存在 → 歧义影响任务 → 歧义改变动作 → 存在合法动作能区分它们 → 区分带来任务收益**。
前四级都是离线或半离线检查，第五级才需要闭环。

| 级 | 问题 | 成本 | 挂掉的性质 | 详细规范 |
| --- | --- | --- | --- | --- |
| **L1** | 在允许观测下，是否真的存在多个都相容的接触假设？ | 天 | 强（穷尽性） | [01_L1_L3_spec.md](01_L1_L3_spec.md) |
| **L2** | 这些歧义是否影响任务方向的代价？ | 天（与 L1 同批线性代数） | 强 | 同上 |
| **L3** | 它们是否会让最优动作改变？ | 天 | 强 | 同上 |
| **L4** | 共同可行动作集合里，是否存在能区分它们的合法动作？ | 天 | **最强（条件性定理）** | [02_L4_oracle_attribution.md](02_L4_oracle_attribution.md) |
| **Oracle** | 连知道全部接触真值，都不比 FREE 强？ | 中等 | 强（指向问题定位错误） | 同上 |
| **归因** | 失败样本在触觉上有可观测签名吗？ | 低 | 中 | 同上 |
| **Stage 2** | 等预算下闭环是否有任务收益？ | 月 | **弱** | [../algorithm_design_blind_tactile_play.md](../algorithm_design_blind_tactile_play.md) §12 |

数据可用性前提见 [00_instrumentation_audit.md](00_instrumentation_audit.md)。

### 为什么顺序不能倒

从 Stage 2 得到的负面是**关于我的方法**的弱负面——它无法关闭任何方向，因为「换更好的探索策略也许就行」永远无法排除。只有 L1–L4 的负面是**关于可行集**的强负面，才能支撑「这条路不用走」这样的结论。

先做 Stage 2 的代价不是浪费时间，而是**你永远分不清「前提错了」还是「实现没做好」**——于是每个负数都能被解释成「再调调就好」，这会变成无底洞。

## 3. 强制门禁：先排除第三种证伪

每一级给出负面之前，必须先排除「**我自己的实现没检测出来**」：

- 假设集枚举漏了掌面/指节候选 → L1 会假阴性。
- 用了指令 $u$ 而不是实际 $\delta q$ → 跟踪误差（实测相对差 34.7%–51.4%）会被混进模式残差。
- 阈值定歪 → L1/L3 结论翻转。
- Jacobian 用了指尖 site 而不是任意接触点 → L2/L3 的方向算错。

**这一步没做，L1–L4 的任何负面结论都是假的。** 具体检查项写在各分级规范里。

## 4. 决策树：每一级挂掉之后走哪条路

### L1 不成立：允许观测已经唯一确定接触模式

首先要排除假设集枚举过窄。排除之后，这本身是**一个强结果**（穷尽性检查），不是失败。

| Fallback | 内容 |
| --- | --- |
| A1 | 收窄主张：刻画**哪一类状态上**歧义存在（子集上的成立条件） |
| A2 | 转向结构性结论：在此观测接口下接触模式可辨识，作为对传感设计的结论 |
| A3 | 检查是否因为候选太粗——把窄带 $\varepsilon_c$ 与模式粒度当成待定的建模选择显式扫一遍 |

### L2 不成立：歧义存在，但对任务代价无影响

含义：$g \in \operatorname{range}(A_m^\top)$，任务相关的代价区间半宽为零。

| Fallback | 内容 |
| --- | --- |
| B1 | 主张改为「**哪一类接触歧义对姿态方向免疫**」，并给出这个子空间的特征 |
| B2 | 换任务方向检验：纯姿态目标 vs 完整 6D 目标 vs 含位置项，看结论是否随任务变化 |
| B3 | 若所有任务方向都免疫 → 歧义在决策层无关，机制不适用，如实报告 |

### L3 不成立：歧义真实、影响任务，但所有假设指向同一动作

这是**最可能发生、也最重要**的一级。含义：任务相关可分辨性 $\neq$ 动作相关可分辨性。

| Fallback | 内容 |
| --- | --- |
| C1 | 这本身是一个反直觉的正面发现：**信息有价值不等于信息有行动价值**。领域默认「触觉信息越丰富越好」，若能证明任务相关的接触歧义在动作层无关，探索预算就不该花在那里——这直接推翻一个默认假设 |
| C2 | 先排除单步 argmin 造成的假阴性：换成滚动多步再判一次 |
| C3 | 若多步仍不改变动作 → 机制在这个任务类上失效，报告并停止，不做 Stage 2 |

### L4 不成立：存在动作相关歧义，但没有合法动作能区分

这是最强的一类负面，但**必须把适用范围写进结论句本身**：

> 在同一表示、同一动作接口、同一观测预算下，共同可行集内不存在可分离方向。

换表示（如柔体建模）或换接口（如允许整段接触调度而不是单步）就是另一套理论，本界不适用。不写清这一条就是过度声明。

| Fallback | 内容 |
| --- | --- |
| D1 | 两步行不行？多步探测是否可行 |
| D2 | 换指重新接触能否产生分离观测 |
| D3 | 指向感知接口的设计结论：当前布局不够用，需要什么布局 |

### Oracle 不成立：知道全部接触真值也不比 FREE 强

| Fallback | 内容 |
| --- | --- |
| E1 | **问题不在接触知识上。** 触觉故事跑偏，该查动作空间、规划或控制 |
| E2 | 重新校准基线：FREE 原设置 282/340（82.9%）、固定初态失配 268/340（78.8%），基线不弱，提升空间本身就是要测量的量，不能预设它很大 |

### Stage 2 不成立：有信息收益，但等预算下任务无改善

如实报告主动探索无收益，退回被动信念更新，不作为主贡献。**不调参续命、不换指标续命、不缩减预算续命。**

## 5. 纪律：预先承诺，不许挪球门

真实的研究失败模式不是「被证伪」，而是「**一直在改假设，改了半年，最后没有任何一个主张是预先承诺过的，也就没有任何一个结论可信**」。常见的形式不是没有勇气让它被证伪，是每次拿到 null 就悄悄挪球门。

因此：

1. **每一级的判据在本文件与分级规范里预先写死**，包括阈值、通过条件、停止条件与 fallback。
2. **任何后续修改都必须以 diff 形式记录**，并写明改的理由和改动的日期。返工不可耻，静默改判据不可接受。
3. **本文件落盘后立即记录指纹**（见文末），后续修改与初版比对可见。
4. **不允许**在拿到结果后重新定义「什么算通过」。
5. **不允许**把弱负面写成强负面——凡结论都要同时写明它的适用范围。

另一条同样重要的纪律：**只探索会改变动作选择的那部分歧义。** 若两个假设对任务进展没有分歧，探索预算为零。这既是算法原则，也是判据原则——它防止用「信息量涨了」冒充「任务变好了」。

## 6. 指标口径（不许用信息熵冒充结果）

结果指标：目标姿态成功率、姿态误差、掉落率、失接触次数、峰值载荷、到达时间、**交互步数**。

诊断指标：信念熵轨迹、P0 阶段消耗的探索预算、阶段切换次数与原因。

**信息熵下降不算结果。** 它只能作为诊断，用来解释结果，不能替代结果。

---

## 7. 立论口径修正（沿用上游审核）

旧 **47/340（13.8%）** 受重置初态影响，**不能**再用于证明动力学失配导致整体崩溃。一次固定失配也不能代表现实物理变化的完整分布。

研究动机应依靠**明确的接触歧义与可重复失效机制**，而不是那一个旧统计。
