**影响：** 推翻 [algorithm_design_blind_tactile_play.md](../algorithm_design_blind_tactile_play.md) §1 与 §5 的前提，并作废 pilot 里"用全局约束残差给接触假设打分"这一整类判据。

## 1. 证据（`models/explicit_model.py::init_model`，原文摘录）

```python
b_o = cs.DM(self.param_.obj_mass_ * self.param_.gravity_)   # 物体质量 × 重力
b_r = self.param_.robot_stiff_ @ cmd
b   = cs.vertcat(b_o, b_r)

v_non_contact = Q_inv @ b / h

contact_force = -sigma * (jac_mat @ Q_inv @ b + phi_vec) \
                - 0.1 * sigma * jac_mat @ Q_inv @ b / h
contact_force = cs.log(1 + cs.exp(beta * contact_force)) / beta   # softplus
v = v_non_contact + Q_inv @ jac_mat.T @ contact_force / h
```

## 2. 三条结论

**2.1 `jac_mat @ qvel = 0` 从来不是 FREE 的约束。**
论文标题里的 complementarity-**free** 指的是：把互补条件替换成一个**软的、可微的接触力模型**。接触力由 softplus 从 $(JQ^{-1}b+\phi)$ 得到，输出的是**力**，不是运动学等式。

**2.2 FREE 的预测器显式含物体质量与重力。**
`b_o = obj_mass_ * gravity_` 直接进入 `b`，而 `b` 同时决定非接触项和接触力。此外 $-0.1\sigma JQ^{-1}b/h$ 项还与步长 $h$ 耦合。
所以"无需物体动力学"在 FREE 的模型内**不成立**。

**2.3 刚性残差测的是模型失配，不是接触模式。**
用 $\|A_hx+J_h\delta q\|$ 给接触假设打分，衡量的是"与理想刚性接触的偏离"，也就是**与 FREE 软模型的失配**。这解释了 pilot 里 adequacy 约等于 1 的现象（预测物体运动不比预测"物体不动"更好）——**不是接触模式判错，是模型根本不同。**

## 3. 对之前立论的直接影响

| 原主张 | 修正后 |
| --- | --- |
| "无需物体动力学" | 只能作为**与 FREE 不同**的声明，**不能**作为"比 FREE 强"的立足点。FREE 的预测器本来就带质量与重力。 |
| "运动学关系里没有质量/惯量/摩擦" | 该句对**理想刚性接触**成立，对 **FREE 的物理**不成立。必须分开陈述，不能混用。 |
