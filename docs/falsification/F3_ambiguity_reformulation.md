## 0. 一句话

F1 与尺度发现杀掉的是**刚性接触关系**（一个运动学等式），不是**动作→观测的响应关系**。
负载归属问题**完全不用前者**，而且它在 0.1 s 尺度上恰好是**可测**的——两个坍塌都绕得开。这可能是目前唯一同时躲过两者的表述。

---

## 1. 两次坍塌到底限制了什么，没限制什么

| 被排除的 | 它的形式 | 为什么它死了 |
| --- | --- | --- |
| 用刚性约束残差定义歧义（F1） | $\lVert A x + J\delta q\rVert \approx 0$ | FREE 是软接触力模型，预测器含质量与重力；该残差测的是与软模型的失配 |
| 把它搬到 ε-探针（尺度） | 同上，换到探针分支 | 探针与基准同为 0.1 s / 50 物理步，**时间尺度没变** |

**两者约束的都是同一个东西：一个把"接触"写成运动学等式的量。** 它们说的是——在 0.1 s、约 0.2 rad 的动作上，$\delta q$ 不能用来预测物体位移。

**它们没有说的：**

- 没有说**输入→输出响应**不可测。恰恰相反，探针实测到了响应：$|d_{\text{obj}}|$ 在 6e-4 – 6.8e-3 量级，而 baseline $|d_{\text{obj}}|$ 是 5.4e-2 – 9.6e-1（`RESULTS_L1_probe.md` §3）。**信号是存在的**，而且在 0.1 s 上存在——因为你本来就需要时间让物体响应。
- 没有说**归属**（哪个接触在承载）不可判别。
- 没有说 0.1 s 尺度上的响应是**线性**的——它明确说了不是（不对称最高 46%，标度最低 0.85）。所以任何用它的判据，**必须是顺序型/二值型，不能是线性预测型**。

**这是重建的立足点。**

## 2. 三个候选表述

三个都满足：(a) 不依赖刚性接触残差；(b) 不辨识物体参数。

### R1 — 承载归属（load attribution）★推荐

**表述。** 对每个指尖 $j$，维护一个二值/序数量：**"指尖 $j$ 的动作对物体运动是否有发言权"**。

**它预测什么可观测差异。** 给指尖 $j$ 一个已记录幅度的探针动作，看物体位姿是否响应：
$|d_{\text{obj}}|$ 显著大于该快照的数值噪声 → $j$ 承载；$\approx$ 机器零 → $j$ **不参与承载**。
判据是**二值的**，不需要线性、不需要接触模型、不需要质量摩擦。

**它在本数据上已经有正例。** `stick nominal` step 7，扰动关节 1（第 0 指），
$|d_{\text{hand}}| = 1.28\times10^{-3}$ / $2.57\times10^{-3}$（随 ε 精确翻倍，手确实动了），
而 $|d_{\text{obj}}| = 3.0\times10^{-15}$ / $5.7\times10^{-15}$——**物体末态逐位不变**。
这是"动作下去了、物体没反应"的干净实例，也是"命令的手指根本没承载"的直接证据。

**为什么它是决策相关的。** 任务动作若要通过某个指尖施加影响，而该指尖不承载，则动作无效。**这个歧义会改变动作选择**（该换哪根手指），因此落进原设计的立论里，而不是一个泛泛的"物体是什么"的问题。

**失效模式。** 两条：
1. **不可测**：物体响应低于噪声（小幅度探针 + 重物 / 强约束）。
2. **不可分**：两个假设都预测"物体不动"（例如"该指不承载"与"该指承载但物体被其他约束锁死"给出相同的二值结果）。此时 R1 必须报 `undetermined`，**不许**报"不承载"。

**要什么数据。** **现有 183 行就能部分测**（16 行探针、4 个合格快照，其中 1 个是机器零正例、1 个非线性）。
**要给结论必须新采数据**，且探针关节必须从**当前有载荷的指**里选。

**杀手。** 若在所有快照上，**任何**指尖扰动都给出可测的物体响应（即每次"物体不动"都能被排除），则 R1 的变量恒为"全部承载"，无信息可谈。

---

### R2 — 局部响应等价类（local response equivalence class）

**表述。** 完全不表示接触。维护一族**局部**"动作→下一观测"的响应模型，从在线历史里拟合。**歧义 = 与历史相容的响应模型集合的规模**；探索 = 挑一个让该集合收缩最快的动作。

**它预测什么可观测差异。** 不同响应模型对同一候选动作给出**不同的预测观测**（下一帧指尖触觉 + 物体位姿）。可分性 = 预测差异 > 噪声。

**失效模式。** 这是**最重的一条**：它就是**很轻的系统辨识**，`route_c_online_response.md` 自己承认了这一点，文献线也确认审稿人会这么归类。另外它数据饥渴——现有 6 个 episode × 30 帧，拟合一族局部模型没有意义。

**要什么数据。** 现有 183 行**只能做可行性演示，不能给结论**；要给结论需要**大量新数据**（数量级：≥10² 条同分布轨迹）。

**杀手。** 历史已经足够把响应模型集合压到单点（在 0.1 s 尺度上，一阶响应很快就可辨认）→ 歧义集合恒为空，探索预算恒为零。

---

### R3 — 未观测支撑的负载上界（unobserved support load bound）

**表述。** 不去问"掌面哪个 geom 在接触"（覆盖率闸门已证明几何几乎唯一确定它），而是维护一个**界**：四指尖以外**最多**承担了多少载荷。

**它预测什么可观测差异。** 指尖力/力矩 + 物体位姿变化 → 解释不了的剩余运动。剩余占比大 → 有外部支撑在起作用。

**失效模式。** 依赖某种力平衡假设；而准静态力平衡**需要接触位置与法向**，掌面那些恰好拿不到。它退化成"用四指尖解释全物体"，正是覆盖率闸门否掉的那个结构。

**要什么数据。** 现有 183 行可测（有真值标签可交叉核对），但要独立验证需要新传感（掌面/指节触觉）。

**杀手。** 若剩余运动占比在所有帧上都 ≈ 0，则隐藏支撑不是问题——但 `RESULTS_coverage_20260923.md` 已经显示 96.4% 的帧有未观测承载接触，所以**这条大概率不会被杀**，代价是它要新传感器才能独立验证。

## 4. 与最接近的先行工作正面比对

引用来自 `task_relevant_info_lit.md`（已核实条目）。

- **TANDEM（arXiv:2203.00798）**：触觉探索与决策联合优化——**机制骨架与我们相同**。但它的任务是**触觉物体识别**，探索目标是**物体属性**。R1 的探索目标是**"这个动作会不会无效"**，即动作集自身的属性。**差别是真实的**，但窄。
- **arXiv:2210.13403**：在手操作 + 触觉 + 任务驱动 + 探索/完成显式权衡，且不依赖已知模型——**这是最危险的一篇**。它平衡的是**全局物体形状**的探索。R1 不探索形状，只探索"哪根手指有发言权"。**差别成立，但需要论文里逐条论证，不能一句话带过。**

**诚实的判断：** R1 相对这两篇的增量是**窄**的。它更像一个**干净的机制 + 一条结构性发现**的组合，不是一个新框架。

## 5. 建议

1. **走 R1**，因为它是唯一同时躲过 F1 与尺度发现、且现有数据已有正例的表述。
2. **把结构性发现放在前面当立论**，而不是把 R1 当方法卖：
   > 几何（已知 CAD + 本体感觉 + 物体位姿）几乎唯一确定**哪些接触存在**（167/167 覆盖，误报率 1.56%，每帧仅 1–6 个候选对）；它**完全不能**说明这些接触**在不在承载**（96.4% 的帧有几何可见、触觉不可见的承载接触）。因此把不确定性建在"接触存在性"上的方法解决的是错的问题。
3. **保留"不可分性"作为保险**（文献线建议）：若 R1 的判据在某些条件下不可分，那个负面结论本身就是一条**界**，可以独立成立。

## 6. 什么会推翻本文件的建议

- 若"任何指尖扰动都给出可测物体响应"在多数快照上成立 → R1 变量无信息，退回 R2/R3。
- 若新采样中"物体不动"的实例无法与"物体被约束锁死"区分 → R1 在多数情形报 `undetermined`，不可用。
- 若逐条论证后发现 R1 相对 2210.13403 的差别守不住 → 应放弃把它当方法，只保留 §5.2 的结构性发现。

**本文件不主张：** R1 已经被验证；R1 能解决 L1；或三次坍塌之后框架仍然完整。它只主张 R1 是**目前唯一没有被已确认的否定结果直接击落**的候选，值得用第一批新数据去检验。
