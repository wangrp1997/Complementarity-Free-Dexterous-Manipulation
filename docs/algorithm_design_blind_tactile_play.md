# 盲把玩式主动触觉在手操作：算法设计（FREE / Allegro 版）

**日期：** 2026-09-22
**状态：** 设计草案。未实现、未跑通、未验证，不构成功效或安全性主张。
**环境：** 现有 FREE 仓库 + Allegro 16 DoF 手（`envs/allegro_env.py`）。
**前置文档：** [research_plan.md](research_plan.md)、[tactile_state_spec.md](tactile_state_spec.md)、[method_routes/review.md](method_routes/review.md)、[observation_sufficiency_20260922.md](observation_sufficiency_20260922.md)、[literature_comparison_20260922.md](literature_comparison_20260922.md)。

本文只做一件事：把「无需物体动力学、无需仿真强化学习、用主动触觉探索把玩物体」这个想法，落成一份能被逐条证伪的算法设计。

## 0. 硬约束（先说清楚，后面全部设计服从这几条）

| 编号 | 约束 | 含义 |
| --- | --- | --- |
| C1 | **FREE 是基线，不能被破坏** | `envs/`、`models/`、`planning/`、`contact/`、`utils/`、`envs/xmls/` 一律不改。`ours` 只新增，不修改。 |
| C2 | **不输入物体动力学** | 控制器不读质量、质心、惯量、摩擦、接触材料参数；也不以辨识它们为目标。 |
| C3 | **无策略预训练** | 不做仿真 RL、不训练策略网络、不需要 replay buffer 或 domain randomization 训练集。 |
| C4 | **动作接口与 FREE 完全一致** | $u_t\in\mathbb R^{16}$，$q^{\text{target}}_t=q_t+u_t$，执行 $frame\_skip\times timestep$。 |

## 1. 为什么「不学动力学」在这里不是妥协，而是更合适的建模选择

这一节是整篇文档的立论基础，也是答辩时最容易被问的地方，所以先写清楚。

在手内重定向的准静态区间内，物体的运动**主要不是由惯性决定的，而是由接触约束决定的**：

1. 若接触处黏着，物体的微小位移 $x$ 由指尖位移通过运动学约束**唯一决定**（最多差一个零空间），这个关系里没有质量、质心、惯量、摩擦。
2. 质量、质心、摩擦只通过一件离散的事影响结果：**这个接触撑不撑得住**，也就是「滑 / 不滑」「接触 / 脱离」。
3. 而离散事件恰恰是触觉**直接可观**的（接触位置、法向载荷、切向相对位移），连续参数则不是。

把这两点合起来看：

> 参数化建模把**最难辨识的部分**（$m,c,I,\mu$：短 episode 里激励本来就不足，TwinTrack 自己也承认激励不足则不可辨识）放进了模型，把**最容易观测的部分**（滑移、脱离）放进了残差。
> 我们反过来：把可观测的离散事件做成状态，把难辨识的连续参数从模型里**删掉**。

人类行为正好支持这个判断：人在黑暗里能把玩一个陌生物体。人不知道它的质量，也不做参数辨识；**人一旦失去接触反馈就做不下去**。因果变量是接触信息，不是物体参数。

**同时必须写下的限制**（否则这一节会被当成过度声明）：

- 该论证只在**准静态**区间成立。抛接、自由飞行、快速动态重定向不在此列，本设计不覆盖。
- 「不建模摩擦」不等于「摩擦不影响结果」。摩擦仍然通过滑移影响成败，我们的处理方式是**检测**而不是**建模**。
- 因此我们得到的是**有条件的**运动学预测 + **可观测的**风险信号，不是任意未知物理下的安全保证。

## 2. 人类盲操作的行为分解，以及逐条对应

「模仿人类盲操作把玩物体」如果不拆成可执行的动作，就只是一句修辞。这里拆成四条，每条给出对应的算法部件。

| 人的行为 | 实际在做什么 | 对应算法部件 |
| --- | --- | --- |
| **不称重、不看，直接开搓** | 不辨识参数，靠接触把物体「滚」过去 | §5 运动学约束预测 $\to$ §8 一步优化 |
| **打滑前会先感觉到** | 用**初期滑移**而不是摩擦系数来控风险，随即捏紧 | §7 滑移监测 + 载荷包络 |
| **不确定时小幅揉搓，确定时果断转** | 动作幅度随置信度变化；探索嵌在操作里，不单独停下来感知 | §6 任务相关歧义 $\to$ 自适应 $\gamma_t$、$\rho_t$ |
| **转到头了就换手指** | 当前接触配置用尽时改成「松一指—挪位—重新接触」 | §9 把玩原语与阶段状态机 |

这是**行为层面的类比和设计原则**，不是关于神经机制的声明，正文里不应写成后者。

另外要和已有的「先感知、后操作」划清界限：我们不做完整三维重建（CAD 已知，重建已知几何没有意义），也不做「先辨识动力学再操作」。探索的目标只有一个——**消除会改变下一步动作选择的接触歧义**。

## 3. 观测边界（沿用 tactile_state_spec，不扩张）

**允许输入：**

- 视觉：物体当前位姿 $T_o=(R,p)$；目标位姿 $T_*$。（仿真里用真值代替，无噪声，需注明。）
- 本体感觉：关节位置 $q_t$、关节速度 $\dot q_t$、过去动作与时间。
- 虚拟指尖触觉：`fingertip0..3` 的有效接触点位置 $p_c$、法向 $n_c$、施于物体的力 $f_c$；力偶按理想化通道单列，非必需。
- 先验：已知物体 CAD、手部运动学（FK/Jacobian 由 CAD + 模型解析计算，不使用 FREE 的 `jac_mat`，因为它混入名义摩擦）。

**禁止输入：** 真实质量/质心/惯量/摩擦、未覆盖接触标签、真实滑动速度、求解器约束状态、完整仿真快照、未来帧。

**已知的能力缺口（必须继承，不能装作不存在）：** 已有审核显示 167 个基准时刻中 **161 帧含四指尖以外的掌面或指节有载荷接触**（96.4%）。四指尖触觉**不是**全手皮肤，也不覆盖全部承载接触。本设计不假设它覆盖，而是把这一点结构性地写进信念集合（§4 的隐藏支撑候选）。

## 4. 核心表示：接触假设集合（Belief）

这是整套算法真正的新东西，也是「不需要物体动力学」的落点。**我们在线维护的不是物体参数，而是「哪些接触在约束物体、以什么方式约束」。**

### 4.1 接触假设的定义

一次观测后，对每个**已观测**指尖接触 $c$ 赋予一个模式：

| 模式 | 含义 | 约束行 |
| --- | --- | --- |
| `STICK` | 物体上的材料点与指尖材料点同步运动 | 3 行（$I_3$） |
| `SLIDE_N` | 只保持法向接触，切向自由 | 1 行（$n_c^\top$） |
| `FREE` | 该接触已脱开 | 0 行 |

对**未观测但几何上可能承载**的位置，生成候选节点：对掌面与各指节的碰撞几何，用 CAD 有符号距离在窄带 $[-\varepsilon_c,+\varepsilon_c]$ 内枚举候选，模式同样取 `STICK / SLIDE_N / FREE`。

> **几何邻近不等于有力、不等于黏着。** 候选只表示「它可能是支撑」，不表示它一定是。这正是不能用 `labels` 里的掌面力去喂控制器的原因。

一个假设 $m$ 就是对上述所有接触的模式指派；把它的行块堆起来得到 $(A_m, J_m)$。

### 4.2 假设集合的规模控制

朴素枚举是 $3^{4+\#\text{candidates}}$，不可行。用三层削减：

1. **几何剪枝**：距离超出窄带的候选直接判 `FREE`，不参与枚举。
2. **因子化 + beam**：按指尖分组分别维护模式后验，只保留联合权重前 $K$ 的假设。因子化是近似（不同指尖的模式通过物体运动相关），必须作为一个已声明的近似，而不是隐含假设。
3. **动作相关性剪枝**：只保留「在任务相关方向上会给出不同动作」的假设（§6 定义）。动作不可区分的假设合并，不占预算。

同时**必须始终保留一个「最大不确定」假设**（所有未观测候选都算作可能支撑），用于安全侧，防止乐观假设把风险抹掉。

### 4.3 权重更新

前后两帧的**允许观测**给出 $x_{\text{obs}}=[\delta p;\,L\delta\theta]$ 与**实际**关节变化 $\delta q=q_{t+1}-q_t$（不是 $u$），对每个假设计算运动学残差

$$r_m = A_m x_{\text{obs}} - J_m\delta q .$$

用固定阈值或明确声明的噪声模型更新 $w_m$。要点：

- 更新只用允许观测，不用 `labels`。
- 残差大只说明**该假设的模型失效**（可能是滑移、可能是关联错误、可能是模式切换），不直接等同于滑移标签。
- 有跟踪误差时，$\delta q\neq u$ 的部分必须单独记录，否则会把关节伺服误差误判成接触模式。

**这一层完全不出现质量、摩擦、惯量。** 它只回答一个问题：现在哪些接触在以什么方式约束物体。

## 5. 运动学关系：模型里没有物体动力学参数

取长度尺度 $L>0$（例如 CAD 包围球半径），把物体小位移无量纲化为

$$x=\begin{bmatrix}\delta p/L\\ \Delta\theta^o\end{bmatrix},\qquad
A_a=\begin{bmatrix}I & -[r_a]_o/L\end{bmatrix}_\times$$

其中 $r_a$ 是接触点关于物体 CAD 原点的位置。对接触所属手部刚体 $h(a)$ 与局部点 $\ell_a$，由手部正运动学求

$$J_a=\frac{\partial \left(T_{h(a)}(q)\,\ell_a\right)}{\partial q}\in\mathbb R^{3\times16}.$$

黏着条件下

$$A_a x = J_a\,\delta q + O(\eta^2).$$

按假设 $m$ 堆叠并用加权左逆：

$$K_m=(A_m^\top W_m A_m)^{-1}A_m^\top W_m J_m,\qquad x_m=K_m\,\delta q .$$

**要点与陷阱（全部继承路线 A 的审核结论）：**

- $J_a$ 必须是对**任意接触点** $\ell_a$ 求导，不能用指尖 site 的 Jacobian 代替（`allegro_fd_fn` 给的是指尖 site，需要扩展）。
- $x_m=K_m u$ 额外用了**理想关节跟踪**假设。已有数据实测指令与实际关节变化的相对差是 **34.7%–51.4%**，所以这只是名义预测，必须验证。
- $A_m$ 不满秩时不要用正则化把不可确定方向伪装成已预测：两个点接触会留下绕两点连线的转动自由度，属结构性不可观测。
- 相容性约束 $(A_mK_m-J_m)u=0$ 不能省略，否则会为不相容的指尖动作虚构一个物体运动。

## 6. 任务相关歧义：只探索「会改变动作选择」的东西

这是把「主动探索」和「把玩」绑在一起的关键，也是相对四项已有工作最可能站住的区别。

### 6.1 什么时候歧义无关紧要

设任务代价的一阶变化为 $g^\top x$（纯姿态目标时 $e=\operatorname{Log}(R^\top R_*)^\vee$，$g=[0;\,-e]$）。

> **条件命题。** 在假设 $m$ 的等式可行集上，$g^\top x$ 取值唯一，当且仅当 $g\in\operatorname{range}(A_m^\top)$。
> 若进一步限制在以可行点为中心的半径 $r$ 零空间球内，任务一阶变化区间的半宽恰为 $r\|P_{\ker A_m}g\|$。

**工程含义：** 若两个假设在这个意义下给出**相同的任务进展**，那这个歧义对当前目标无害，不需要花预算探索。这就是「探索多少，由转到目标姿态所需的接触信息决定」的可操作版本。

### 6.2 动作相关性判据

假设 $m,m'$ 称为**动作相关**，当且仅当在各自最优动作下，任务相关方向的差异超过阈值：

$$\big\|\Pi\,(u^*_m-u^*_{m'})\big\|>\delta_u .$$

只有存在动作相关假设对时，才允许开启探索项。这是可证伪的设计选择：如果实践中从未出现动作相关对，说明这套机制没有作用，应报告而不是继续调参。

### 6.3 探测项

在任务相关子空间上用预测分离度定义

$$D(u)=\sum_{m}w_m\big\|\Pi\,(K_m-\bar K)u\big\|^2_{\Sigma^{-1}},\qquad \bar K=\sum_m w_mK_m .$$

$\Sigma$ 是声明来源的观测误差尺度，**不能**从隐藏物理参数算。

**注意 $D$ 不是信息增益**，只是模式预测分离度。它的正当性只能由「分离 $\to$ 后续动作改变 $\to$ 任务变好」这条链验证。

### 6.4 让探索自适应（对应「不确定时揉搓、确定时果断」）

$$\gamma_t=\gamma_0\cdot\mathbb 1[\exists\ \text{动作相关假设对}],\qquad \rho_t=\rho_{\max}-(\rho_{\max}-\rho_{\min})\,H(w_t)$$

其中 $H$ 是权重的归一化熵。置信度低 $\to$ 幅度小、探索权重大；置信度收敛 $\to$ 幅度放开、探索项归零。

这条规则同时给出了一个明确的失败条件：**若共同可行动作集合只有零动作，或对所有可行动作都有 $D(u)=0$，则本机制失效**，必须如实报告，不能用「接触图更丰富」搪塞。

## 7. 没有摩擦模型，风险怎么管

不能写摩擦锥，所以不使用任何自称真实的摩擦锥。改用三个**只用允许观测**的量：

1. **载荷包络（经验标定）。** 记录本 episode 内物体确实被稳定持有时的各指法向载荷 $\ell_{\text{ref},i}$（例如起始稳定段的运行最小值），要求预测载荷 $\hat\ell_i(u)\ge\alpha\,\ell_{\text{ref},i}$。
   *诚实标注：* 这是**经验**安全裕度，不是摩擦锥，也不保证不被打破。
2. **包络度（几何，不需摩擦）。** 检查接触法向是否正张成 $\mathbb R^3$（原点落在法向凸包内部），并保持接触数不低于阈值。这是**必要非充分**条件，但完全不依赖摩擦知识。
3. **滑移监测（初期滑移）。** 对标记为 `STICK` 的接触，逐帧计算材料点切向相对位移；超阈值即降级为 `SLIDE_N` 并立即重规划。
   *已知代价：* 检测至少滞后一个控制周期；这是**检测**不是**预防**，不能宣传成安全保证。

**隐藏支撑的特殊处理（对应 96.4% 的审核结果）：** 只要存在未排除的隐藏支撑假设，就自动收紧幅度 $\rho_t\to\rho_{\text{small}}$，只做小步、保包络的动作。宁可慢，不赌一个没看见的支撑。

## 8. 一步优化与主循环

每个控制周期求解一个小规模约束优化（沿用 FREE 的 16 维动作接口）：

$$\min_{u,\,s}\;\; s+\lambda\|u\|^2-\gamma_t D(u)$$

$$\text{s.t.}\quad \big\|\Pi(K_mu-x^\star)\big\|^2_Q\le s \quad\forall m\in\mathcal M_{\text{eff}}$$

$$\quad (A_mK_m-J_m)u=0,\qquad q_{\min}\le q+u\le q_{\max},\qquad \|u\|_\infty\le\rho_t$$

$$\quad \hat\ell_i(u)\ge\alpha\,\ell_{\text{ref},i},\qquad \text{enclosure}(u)\ge\text{thr}$$

梯度来源是解析的：$\nabla_u\|K_mu-x^\star\|_Q^2=2K_m^\top Q(K_mu-x^\star)$，加上 SO(3) 对数映射的解析 Jacobian。加 $-\gamma D$ 后一般非凸，用信赖域多起点求局部解，**不宣称全局最优**。

**主循环（单周期）：**

```
观测 (T_o, q, q̇, 指尖接触) + 目标 T*
   ↓
更新接触假设权重 w_m（残差 r_m）        ← §4.3
   ↓
滑移/载荷/包络检查，必要时重建假设集       ← §7
   ↓
判断是否存在动作相关假设对                ← §6.2
   ↓
求解一步优化（γ_t、ρ_t 按置信度设定）     ← 本节
   ↓
执行 u_t（与 FREE 相同接口）
   ↓
检查模式切换事件（接触建立/脱离/滑移）→ 重规划
```

注意这是**滚动的单步闭环**，不是多步 MPC。多步以后可以加，但不是本设计成立的前提。

## 9. 把玩原语与阶段状态机

四个阶段的差别只在 $(\gamma_t,\rho_t)$ 与可行约束，求解器是同一个。

| 阶段 | 触发（只用允许观测） | 行为 | 对应人类动作 |
| --- | --- | --- | --- |
| **P0 盲摸 / Resolve** | 起始或信念熵 $H(w_t)$ 高 | 小幅度、在姿态包络内最大化 $D(u)$；预算有上限 | 在黑暗中揉搓试探 |
| **P1 滚动 / Roll** | 信念收敛且任务方向可行 | 沿滚动流形推进目标姿态 | 熟练地搓转 |
| **P2 换指 / Gait** | 任务方向可行集为空，或所需转角超出关节行程 | 一次松一站，保包络地挪位再接触 | 转到头了换手指 |
| **P3 微调 / Align** | 接近目标姿态 | 小幅度、紧包络、密滑移检查 | 对准时的细微调整 |

阶段切换全部由**可观测事件**触发，必须记录切换次数与原因，作为诊断指标而非调参对象。

## 10. 与 FREE 的隔离：怎么保证基线不被破坏

| 规则 | 说明 |
| --- | --- |
| 只新增，不修改 | 新代码放 `ours/` 与 `examples/mpc/ours/`；`docs/` 只加文档 |
| 冻结既有目录 | `envs/`、`models/`、`planning/`、`contact/`、`utils/`、`envs/xmls/` 一字不改；`params.py` 不动 |
| 复用而不重写执行 | 直接调 `MjSimulator.step / get_state / get_jpos`；`ours` 自带任务参数文件，不污染 FREE 的 |
| 观测只读 | 复用已有 `ours/tactile_observation.py`（已在完整 `MjData` 副本上计算；审核已验证插入观察器后轨迹逐位不变） |
| 成功判据同源 | 从 FREE 的评测脚本复制，保证数字可对比 |
| 回归检查 | 改动前后对 FREE 文件做 SHA-256 比对 + 重跑 17 物体基准，逐物体确认一致 |

原则一句话：**ours 是 FREE 的一个并列执行器，不是 FREE 的补丁。**

## 12. 实验设计与可证伪判据

顺序不能颠倒，前一步不成立就不做下一步。

**Stage 0（离线，只用已有 167 帧）：歧义存在吗？**
在允许观测下构造假设集，检查是否存在一对假设：(i) 都与观测相容，且 (ii) 会给出不同的**任务相关**动作。若不存在，机制的前提就不成立，先修正假设集或感知接口。

**Stage 1（离线/半离线）：有合法动作能区分它们吗？**
检查共同可行动作集合中是否存在分离方向。若共同可行集只有零动作，或所有可行动作的 $D(u)=0$，则**探索动作不存在**——这是必须如实报告的失败，不是调参问题。

**Stage 2（闭环，同初态受控对照）：区分带来任务收益了吗？**

| 对照组 | 说明 |
| --- | --- |
| FREE（原样） | 主基线。它不用触觉，因此信息预算是**更少**的，比较是公平的。 |
| ours − probe | 同样的状态与优化，关掉 $D(u)$。检验「主动」的净贡献。 |
| ours + 通用信息 | 用通用信息量替代任务相关项。检验「任务相关」是否必要。 |
| ours + 任务相关 probe | 本文方法。 |

固定量：完整初始仿真状态、成功率判据、动作预算、时间预算、计算预算。

**指标：** 目标姿态成功率、姿态误差、掉落率、失接触次数、峰值载荷、到达时间、**交互步数**、信念熵轨迹、P0 阶段消耗的探索预算。

**Phase 3（分布外）：** 物理参数超出当前固定失配、接触模式切换、滑移场景。注意现有 `unknown-dyn` 只是一套固定配置（且实测未改变指尖有效摩擦），**不能**当随机化分布用。

**停止条件（提前写死，避免事后找理由）：**

- 不存在动作相关假设对 $\to$ 报告机制不适用，不做 Stage 2。
- 存在但无合法分离动作 $\to$ 报告并修改假设或感知接口。
- 有分离但等预算下任务无改善 $\to$ 报告主动探索无收益，退回被动更新，不作为论文主贡献。

**关于 RL 基线：** 本阶段（FREE 环境）不做 RL 对照，这与「我们的方法不用仿真 RL」是两回事。论文级的 RL 对照需要在 Isaac Lab 侧另建（POISE / WM-Craftnet 用的是那边），属于后续阶段，不混进本设计。

## 13. 已知失败模式（写下来是为了不再事后解释）

1. **隐藏支撑占主导。** 96.4% 的帧有未覆盖载荷接触。若信念长期无法收敛，$\rho_t$ 会一直很小，任务几乎不走 —— 这是设计的保守后果，不是 bug。需要提前评估它对成功率的影响上限。
2. **不可分离歧义。** 见 §6.4。这是机制级失败，必须报告。
3. **准静态假设被破坏。** 快速动作或自由飞行段会让运动学关系失效。
4. **滑移检测滞后。** 至少一个控制周期，严重滑移可能来不及。
5. **跟踪误差污染推断。** 指令与实际关节变化差 34.7%–51.4%，若不单独建模，会被误判成模式残差。
6. **信息有收益但代价更高。** 探索占用预算，可能净损失任务时间。这是必须诚实报告的负结果。
