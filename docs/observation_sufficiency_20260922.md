# 触觉观测充分性审核：已有数据支持什么

本轮结论：**当前四指尖观测不能被当作全部承载接触的观测；这不等于已经证明“触觉＋视觉＋历史”无法支持控制。**研究仍可继续，但方法必须把未覆盖接触和接触模式的不确定性写出来，不能直接假设物体只由已观测指尖约束。

本轮只读已有 `docs/data/tactile_probe_v2_review_20260920`，没有扩采、训练、实施控制器或改动 FREE。原研究计划保持不变。统计细节见 [JSON](observation_sufficiency_20260922.json)，可复现程序见 [分析脚本](analyze_observation_sufficiency_20260922.py)。

## 1. 审核口径

6 个 episode、183 条动作记录中，只取 `probe_sign == 0` 的 167 个基准动作起始时刻，每个 episode 的 `source_step` 唯一。正负扰动分支共享起点，不能重复计入观测覆盖率；末态也不重复混入本表。样本来自 3 个物体、2 套物理条件、每套 1 个 seed 的短 FREE 轨迹，不代表任务总体分布。

有载荷接触采用原观察器阈值：接触法向力大于 `1e-8 N`。由 `labels.npz` 中的接触几何 ID 与法向载荷审核感知覆盖，实际控制输入仍只有四指尖记录、视觉位姿、本体感觉及允许历史。真实物体速度、完整积分状态和未覆盖接触均只作审核真值。

没有读取真实物体物理参数作为状态特征，没有仿真推进或重新生成轨迹。MuJoCo 在脚本中只用于加载几何命名/状态布局和 `mj_differentiatePos` 计算姿态差分；未调用 `mj_step` 或 `mj_forward`。18 个原始 inputs/labels/metadata 文件的 SHA-256 在分析后逐一核验不变。

至少两个有载荷指尖合计 **26/167（15.6%）**。因此当前数据里的“四指状态图”多数时候只有 0–1 个接触节点，不能按四指同时有效接触来推导。

| 接触区域 | 有载荷接触点事件数 | 出现帧数 | 法向载荷幅值跨帧累加 |
| --- | ---: | ---: | ---: |
| 四指尖 | 269 | 85 | 285.881 N |
| 掌面 | 459 | 147 | 208.932 N |
| 非指尖指节 | 252 | 112 | 165.180 N |
| 地面／其他 | 0 | 0 | 0 |

同一帧可含多个区域；接触点事件是求解器离散点在采样帧中的出现次数，不是独立物理接触或独立实验。指尖占记录的接触点事件 **27.4%**，占法向载荷幅值累加 **43.3%**。后者只是不同方向、不同时间的正标量累加，**不是净力占比、支撑比例、力闭合程度或稳定性指标**。

- **161/167（96.4%）** 帧含未覆盖的有载荷接触。
- 82 个“无指尖触觉”帧全部仍有物体接触。因此“指尖全零”不能标成物体没有接触，更不能直接标成掉落。
- 仅 6 帧的全部有载荷接触均落在指尖，其中多指帧仅 2 个：`mug nominal step 9`、`stick unknown-dyn step 11`。这只是接触覆盖筛选，不代表已经满足动作界、可探索性或安全条件。

分 episode 的 `0/1/≥2` 指尖帧数分别为：cube nominal `13/16/1`，cube unknown-dyn `19/11/0`，mug nominal `17/10/3`，mug unknown-dyn `6/5/6`，stick nominal `19/6/5`，stick unknown-dyn `8/11/11`。

结论不由数值极小接触单独造成：将每个离散点阈值升到 `0.01 N`，未覆盖接触仍出现在 161 帧；升到 `0.1 N` 仍有 130 帧。阈值诊断不能代替真实传感器灵敏度模型，且每点阈值受离散化影响。

## 3. 多点记录与每指摘要：保留了什么、损失了什么

167 帧共 113 个有效“指尖×时刻”记录，其中 **50/113（44.2%）** 含多个离散接触点；点数直方图为 `1:63、2:6、3:13、5:31`。

修正后的摘要保存独立的合力与关于 CAD 原点的合力矩。本轮重新由全部原始点求和，二者与摘要误差均为 0。因此不能说“每指摘要丢掉了总力/总力矩”。损失的是点内位置、法向及载荷分布，是否影响任务需要针对性验证。

只取最强接触点会有明显载荷遗漏：多点指尖记录中最强点占该指尖法向载荷的中位数为 **20.08%**。但不能反过来把五个仿真点视为五个独立触觉传感元件：这些点通常相距很近，多点记录的点集直径中位数约 **0.047 mm**，全体最大约 **2.70 mm**，具有明显的求解器离散属性。

不能用“加权接触中心 × 合力”替代摘要里的独立力矩：本样本两者差值范数中位数为 `0.000673 N·m`，最大 `0.01793 N·m`；差值同时可能包含局部接触力偶和分布效应，不单独归因于几何压缩。当前法向、接触力偶和点级分布仍属于理想虚拟感知能力，真实硬件是否能提供需另行声明。

已有 [几何审核](method_routes/review.md) 显示：四个配对快照的全点假想黏着矩阵数值秩均为 6，每指中心压缩后三个为秩 5；但三个双指快照全点矩阵的最小奇异值仅 `0.00064–0.00102`（长度尺度 `0.05 m`），不能靠近乎重合的离散点制造可靠的六维约束。四个基准动作的跟踪相对误差为 `34.7%–51.4%`，材料点末态差最大为 `8.24–15.87 mm`，也不支持整个 `0.1 s` 周期都固定黏着。这是条件假设诊断，不是滑移标签或所有几何方法都无效的证明。

接触图仍有价值，但边是已有节点观测的结构化关系，不会凭空补足掌面载荷、滑移模式或物体速度。上述问题不能靠增加 GNN 自动消失。

## 4. 历史与隐藏状态检查

**关节速度没有漏采。** `joint_velocity` 和 `next_joint_velocity` 已记录，状态规范也包含它们。161 对相邻基准记录的状态、关节速度逐位连续。

**上一控制目标能够恢复。** 对这 161 个非初始时刻，上一时刻 `q + action` 与当前积分状态里的 `ctrl` 精确相等，误差为 0。当前 XML 的执行器 activation state 维数为 0，`step` 又把控制设成当前 `q+u`；不能把上一目标当作一个已经证实漏采、独立存在的隐含执行器状态。在线接口应保留自己的动作/目标历史，初始控制约定也应明确；在真实硬件含滤波/延迟时另审。

**单帧视觉姿态并不包含物体速度。** 真速度在 labels 中，仅用于审核。161 个有历史时刻的瞬时平移速度中位数 `0.0122 m/s`、角速度中位数 `0.2995 rad/s`。由过去两帧位姿构造的 `0.1 s` 后向平均速度，与端点瞬时速度的差值范数中位数分别为 `0.0163 m/s`、`0.5030 rad/s`。平均速度与瞬时速度本来不同，不能把这个差直接当作某个已实现滤波器的误差；它提示不能默认为每步已经静止，或认为 10 Hz 两帧差分就提供精确当前速度。

92/167（55.1%）条基准动作的起末指尖接触 mask 不同。起末相同也不排除中间接触切换。当前边界采样不足以确定整个周期的接触模式持续性；这一问题影响动作观测模型和信息项，不能用当前瞬时力自动补全。

对同一物体搜索完整当前候选观测（位姿/关节位置、关节速度、四指摘要、全部指尖点）在 `1e-10` 绝对容差内的重复，结果为 0。这个容差只是数值重复检查，未定义现实噪声下“相似状态”。因此没有足够重复状态、相同动作而隐藏接触不同的样本，**不能从本数据得出同观测必然异响应，也不能从没有碰到反例得出状态充分**。

四个配对实验改变的是同一完整物理状态下的动作，控制了隐藏状态；它们并没有检查不同隐藏状态能否映射到同一允许观测。因此配对响应一致性与状态充分性是两个问题。

## 5. 对研究路线的含义与最低成本下一验证

本结果否定的是“当前 FREE 轨迹的承载接触都被四指尖直接看见”这一假设，**不否定部分观测下的在线操作路线**。充分性应针对所需动作判断：允许保留接触认知/历史，只要剩余歧义不会使目标推进与接触风险判断失真，不必先恢复全部物理状态或物体参数。

建议下一步先做一项明确、可证伪的现有数据工作：用已知物体 CAD、全手几何、视觉位姿和关节状态，列出未覆盖指节/掌面的几何接触候选；再检查这些候选是否包含 labels 审核到的实际接触，以及是否存在触觉/视觉历史无法排除、却会改变目标动作选择的支撑假设。几何邻近只构成候选，不代表有载荷、黏着或已知摩擦；真值只用于评价候选遗漏，禁止把 labels 掌面力直接喂给 `ours`。

方法验证可以区分两个受控场景：先在指尖覆盖全部相关接触的场景检验多指几何与任务方向关系；再在固定掌面参与但未感知载荷的场景检验认知更新是否仍有用。现有仅两个“多指且全覆盖”帧尚未满足完整实验资格，不能直接宣称这两个场景已验证。

若需要新增动作实验，应先选定一个具体接触歧义及它影响的任务方向，再比较两三个满足动作界的候选动作，检验观察是否能排除影响动作选择的假设。没有可分动作时先修改方法假设；不要泛采更多 FREE 轨迹或先训练网络。需要新增接触传感覆盖、缩短采样间隔还是历史认知就足够，应由该失败来源决定，当前不能直接宣布必须扩大硬件覆盖。

本次不提供 Markov 性、状态充分性、闭环稳定性或安全保证。可以继续建立方法，但应使用“结构化多指触觉＋视觉/本体历史＋未决接触假设”的表述，避免把当前四指观测直接称为完整接触状态。
