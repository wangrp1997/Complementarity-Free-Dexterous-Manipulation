# 多指触觉候选状态与最小验证规范

本文落实当前设定：已知物体 CAD、手部运动学和视觉物体位姿，物体质量、质心、惯量、摩擦及接触材料参数未知，采用在线动作优化。它补充原计划，不覆盖 `research_plan.md`；本轮不实现优化器或离线训练。

## 1. 动作与感知边界

动作沿用 `envs/allegro_env.py::step`：

\[
u_t\in\mathbb R^{16},\qquad q^{\rm target}_t=q^r_t+u_t.
\]

这是关节目标位置增量，不是力矩、实际关节位移或物体速度。响应须对应同一控制时长 `frame_skip × model.opt.timestep`。零动作只是把目标设为当前角度，不等于已验证的安全保持动作。

当前 XML 没有触觉图像、触觉阵列或 touch/force sensor。仿真通过接触求解结果构造**理想化虚拟触觉**，限定四个碰撞几何 `fingertip0..3`。其他指节、掌面、地面不在传感覆盖内，不能将四指感知称作全手皮肤感知。

| 信息层 | 来源和内容 | 使用边界 |
| --- | --- | --- |
| 虚拟指尖感知 | 各有效接触位置、施于物体的力；法向与接触力偶按理想传感能力单列 | 是本仿真输入接口；现实传感器是否提供这些量需另验证 |
| 视觉、本体感觉 | 物体位姿、目标姿态、关节位置/速度、指尖位姿、过去动作及时间 | 仿真真值代替视觉/编码器，注明无噪声；物体真速度不是默认视觉输入 |
| 已知几何与历史特征 | CAD 法向、指间几何关系、几何 Jacobian、力分布、短时变化 | 仅由 CAD、运动学及当前/过去允许观测计算 |
| 仅评估真值 | 真实物理参数、求解器状态、未覆盖接触、真实接触距离、真实滑动速度、完整仿真快照 | 独立保存供诊断与标签使用，控制器不得读取 |

接触法向有两条来源：虚拟传感器直接输出属于理想化能力；由 CAD、视觉位姿与接触位置计算属于几何推导。棱边附近法向可能多值。接触力偶也不是三轴力传感器必然测得的量，后续需比较去掉这一信息的情形。没有图像、压力面积和直接滑移传感读数，就不虚构相应输入字段。

真实碰撞距离不是触觉读数。由 CAD 与可观测位姿重新计算的距离或 Jacobian 可以使用；FREE 的 `jac_mat` 混入名义摩擦 `mu_object_`，不能直接作为无物理参数的几何模型。`phi_vec`、`jac_mat` 不属于本观测接口。

## 2. 坐标、力与力矩

设已配准的物体 CAD 坐标到世界坐标为 `(R_o,p_o)`，跨指关系统一在物体坐标中：

\[
p_c^o=R_o^\top(p_c^w-p_o),\quad f_c^o=R_o^\top f_c^w,\quad n_c^o=R_o^\top n_c^w.
\]

约定力为**指尖施于物体**，法向从指尖指入物体，压缩法向力 `f_n = n_cᵀ f_c`。MuJoCo 接触轴按行保存，世界法向来自 `frame[0, :]`；物体是 geom1/geom2 时须同步转换法向、力与力偶符号。不同接触局部切向分量不能直接相加。

接触点力偶为 `τ_c`，关于 CAD 原点的力矩为：

\[
\tau_{O,c}^o=p_c^o\times f_c^o+\tau_c^o.
\]

当前以注册的物体 body 坐标作为 CAD 坐标；原点不是未知 COM。四指合力/力矩仅为**已感知指尖贡献**，不含重力、掌面等其他贡献，不能据此声称净外力平衡、力闭合或安全。

## 3. 节点、边与短时历史

四个节点对应四个指尖，无接触节点也保留。指尖 `i` 保存全部有效接触：

\[
\mathcal C_i(t)=\{(p_c^o,n_c^o,f_c^o,\tau_c^o)\}_{c\in i}.
\]

原始接触集合不截断为最强接触。修正后的节点摘要 `tactile` 为 `(4,14)`：接触标志 1 维、法向载荷加权接触中心 3 维、法向载荷加权法向 3 维、合力 3 维、关于 CAD 原点的合力矩 3 维、法向载荷总量 1 维。摘要不能替代原始集合；接触数受求解器离散方式影响，单独作为诊断量。

无接触用显式标志区分零值与缺测。加权法向不强制归一，抵消可能有意义；加权中心不是实际单接触点，不能用“中心 × 合力”替代独立累加的力矩。接触 ID 通常不能直接跨帧匹配，点级差分需要关联规则；初版历史可先使用指尖级合力/力矩和接触开关。

指尖对组成至多六条无向边，带双方接触 mask，候选特征为：

- 接触中心相对位置/距离，必要时保留跨节点的点对几何；
- 法向夹角或法向分布关系；
- 法向载荷比例、合力方向关系、关于 CAD 原点的力矩协同/抵消；
- 接触建立/脱离时序与短历史力变化。

这些量描述几何和载荷关系，不能提前赋予“稳定支撑”“可安全松指”语义。`||f_t||/(f_n+ε)` 仅为切向载荷指标；摩擦未知时不是已知摩擦锥裕度，也不能单独标为滑移。

候选状态写为：

\[
\bar z_t=(T_o(t),q_t^r,\dot q_t^r,\{\mathcal C_i(t)\},E_t,H_t),
\]

其中历史 `H_t` 只含当前及过去观测、动作和时间，目标姿态另作为任务条件。**未证明这一表示充分或具有 Markov 性**；隐藏速度、摩擦、形变历史可能让相近观测对应不同响应。

接触图是数据结构，GNN 是可选可学习编码器，当前不引入。先比较“力信息”“力+接触几何”“多指关系”“再加短历史”的作用，不因使用图就要求训练网络。

## 4. 状态之后仍需建立的方法

顺序为：可靠原始记录 → 参数无关的几何/关系特征 → 明确局部接触假设 → 在线局部响应与优化。

几何 Jacobian 连接接触点与关节位置，**不能单凭 CAD 把关节目标增量变为物体姿态/接触力响应**。中间包含实际关节跟踪、接触模式、未知摩擦/柔顺性和物体运动。应明确哪些关系解析近似、哪些局部量由已发生动作在线更新，何时失效；图/GNN 不会自动给出这一梯度。

固定接触模式下可考察 `Δy ≈ B_t Δu`，但这只是待检验的候选关系。在线更新局部响应不等于显式辨识质量/惯量，不要求预训练；少量方向探测不能自动辨识完整 16 维响应。模式切换处可能不光滑，平滑近似也不自带真实梯度或安全保证。

已知 CAD 后，主动触觉获取的是**当前接触配置、载荷、模式与任务相关局部响应**，不是恢复已知全局几何。只有证明动作选择获取的信息帮助后续操作，才形成任务驱动探索的证据。

## 5. 最小可证伪实验与数据边界

先验证有效接触筛选、geom 顺序符号、多接触求和、指尖覆盖、空接触标志、观察不修改物理状态，以及动作前后完整记录。旧版触觉数组存在提取和聚合错误，不能直接给研究结论。

随后从少量 FREE 轨迹选取快照，以固定物理条件下的**同一完整仿真状态**分别执行基准动作 `u₀` 与 `u₀ ± εd`，再以另一幅度检查局部一致性。当前采集脚本以 FREE 动作为 `u₀`、少数关节方向为 `d`，不代表覆盖全部动作空间。每个分支恢复包括控制历史/求解器状态的快照；不能把连续轨迹中不同状态的正负动作当作配对实验。

记录前后触觉、关节与视觉位姿、时间、基准/实际动作及扰动。关节限位或裁剪改变正负对称性时必须记录或跳过。物体旋转用 SO(3) 旋转差，不用四元数分量差作为转角。配对差分只用于离线诊断，不能作为在线控制可免费查询的梯度。小幅扰动与 FREE 基准动作都不保证安全，失接触/掉落属于应保留的结果。

可证伪问题包括：两种幅度的响应方向是否一致；接触切换是否使局部近似失效；相似候选状态下同一动作是否频繁产生相反响应；增加接触几何、多指关系、短历史能否减少冲突。若失败，应报告状态/局部假设不足，不能直接归因于数据少或自动改用 GNN。

物理条件对照须控制初始化与有效参数：当前 `unknown-dyn` 是一套固定 COM/惯量/物体 geom 摩擦设置，质量未变，不是广泛随机化。旧 helper 在当前 MuJoCo 版本调用 `mj_setConst` 后会重置初态；新采集脚本须保存恢复完整状态。且物体 geom 摩擦降低未必降低实际指尖配对摩擦，应记录生效接触参数；旧 nominal/mismatch 差异不能全部归因于动力学，不能把此配置称为已验证摩擦扰动。

普通 FREE 轨迹只适合描述分布和选快照；同快照分支可检验该场景的动作影响，但不能证明状态因果充分性、跨物体推广或真实安全。开发与保留验证场景分开，评估在线方法时每个 episode 重置估计，禁止读取未来帧/评估标签。后续先推导方法再确定需要补采哪些条件。

## 6. 当前交付与未决问题

本轮是修正接口、少量采集验证与状态规范，未实现训练或 `ours` 优化器。接口的具体数值字段及列顺序由 `ours/tactile_observation.py::schema_metadata` 给出；采集文件中的诊断字段不因与输入同存就成为允许控制输入，物理参数与完整快照须独立保存。

仍需建立：可辨识的局部方向、所需历史长度、模式切换处理、未知摩擦下可执行约束，以及姿态进展与信息获取的权衡。误差上界、安全 fallback、递归可行性与稳定性均未证明；FREE nominal 是参考基线，不是物理 oracle 或性能上限。
